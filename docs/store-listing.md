## 자세한 설명

갑자기 퇴원 날짜를 듣고 막막할 때, 씩씩케어가 3분 안에 정리해 드려요.

■ 우리 가족이 받을 수 있는 공공 지원
질문 5개에 답하면 전국·지역 공공 지원 47가지 중 해당할 가능성이 높은 것을 찾아 드려요. 신청하는 곳, 필요한 서류, 마감일을 함께 알려줘요. 특정 업체로 유도하지 않아요.

■ 퇴원 날 챙길 서류
실손보험 청구에 필요한 서류 4가지를 퇴원 날 한 번에 받을 수 있게 체크해요.

■ 가족과 할 일 나누기
링크 하나로 가족을 초대하고, ‘내가 할게’ 한 번으로 일을 나눠요. 누가 맡았고 끝냈는지 알림으로 알려줘요.

■ 가족 돌봄 달력과 알림
병원 일정, 퇴원일, 지원 신청 마감을 한 달력에서 봐요. 전날 저녁과 당일에 알림이 와요.

■ 저녁 10초 안부 기록과 외래 리포트
약, 체온, 통증을 하루 한 번 기록하면 외래 날 의료진에게 보여줄 한 장 요약이 만들어져요.

■ 돌봄 비서 씩씩이
보관한 서류와 우리 집 일정·지원 정보에 있는 내용만 쉽게 풀어 알려줘요. 답마다 근거를 보여줘요.

씩씩케어는 의료 상담이나 진단을 하지 않아요. 지원 대상 여부는 신청을 받는 기관이 최종 결정해요. 응급 상황에는 119에 연락하세요.

## Play Console ‘데이터 보안’ 답안

| 질문 | 답 |
| --- | --- |
| 데이터를 수집하거나 공유하나요 | 수집함. 제3자와 공유하지 않음(처리 위탁만) |
| 전송 중 암호화 | 예 (HTTPS) |
| 삭제 요청 방법 | 앱 안 [전체 > 설정 > 전체 삭제] 또는 [가족에서 나가기] |
| 개인 정보 > 이름 | 수집 (가족에게 보일 이름, 앱 기능) |
| 개인 정보 > 사용자 ID | 수집 (카카오 계정을 연결한 경우의 카카오 회원번호, 계정 관리) |
| 건강 및 피트니스 > 건강 정보 | 수집 (입원 이유 큰 분류, 저녁 안부 기록, 앱 기능) |
| 사진 및 동영상 | 수집하지 않음 (서류 사진은 글자를 읽은 뒤 저장하지 않음. 처리 목적 전송만) |
| 앱 활동 > 앱 상호작용 | 수집 (기능 사용 횟수, 분석. 이름·주소 없이) |
| 기기 또는 기타 ID | 수집 (알림 토큰, 앱 기능) |
| 위치·연락처·금융 정보 | 수집하지 않음 |

건강 앱 신고: 의료 기기 아님, 진단·치료 기능 없음.

## App Store ‘앱 개인정보 보호’ 답안

- 사용자에게 연결된 데이터: 이름, 건강 정보, 사용자 ID, 기기 ID(알림 토큰) — 모두 ‘앱 기능’ 목적
- 사용자에게 연결되지 않은 데이터: 사용 데이터(제품 상호작용) — ‘분석’ 목적
- 추적: 하지 않음

## App Store 심사 메모 (지침 4.2 대비)

이 앱은 웹 화면을 보여주는 것에 더해 다음 네이티브 기능을 제공한다: 할 일·지원 마감·저녁 안부 예약 알림과 알림에서 바로 기록, 가족 활동 푸시, 문서 스캐너(VisionKit)로 서류 촬영, 외래 리포트 화면 밝기 조절, 유니버설 링크로 가족 초대 열기, 오프라인 안내 화면.
심사용 체험: 첫 화면에서 동의 후 [시작하기]를 누르면 계정 없이 바로 쓸 수 있다.
