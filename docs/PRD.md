# 씩씩케어 (BraveCare) 제품 기획서 (PRD v3.7)

> **문서 버전:** v3.7 (2026-11 최신 릴리즈 반영)  
> **상태:** 배포 완료 및 운영 중  
> **서비스 URL:** [https://bravecare-kr.vercel.app](https://bravecare-kr.vercel.app)  
> **원칙:** 의료법 제27조 준수, 이모티콘 일절 배제, 무가입 초경량 온보딩, 제로 리텐션(Zero-Retention) 개인정보 보호

## 1. 제품 개요 및 문제 정의

### 1.1. 배경 및 문제
- **갑작스러운 퇴원 통보:** 대형 병원은 수술·치료 후 퇴원 전날(D-1) 오후나 당일 아침에 급작스럽게 퇴원을 통보합니다.
- **정보 비대칭과 행정 공백:** 경황이 없는 환자와 맞벌이 보호자는 원무과 4종 필수 서류, 공공 복지제도 신청 기한, 주말 원무과 휴무 여부를 모른 채 퇴원하여 보험금을 놓치거나 병원을 재방문하는 불편을 겪습니다.
- **가족 간 간병 분담 갈등:** 누가 외래에 동행하고, 누가 서류를 발급받을지 카톡방에서 서로 눈치를 보거나 서운함이 생깁니다.

### 1.2. 솔루션 (씩씩케어)
- **5문항 무가입 온보딩:** 1분 만에 환자 맞춤형 4단계 회복 타임라인과 26종 공공 복지 매칭 결과를 도출합니다.
- **실손24 공공데이터 자동 판별:** 병원명 검색 시 실손24 전산 청구 여부를 실시간 확인하고 미지원 병원은 4종 서류 패키지를 안내합니다.
- **공유 링크(Capability URL) 기반 역할 분담:** 링크 하나로 가족이 가입 없이 합류해 [내가 할게]로 역할을 맡고, 캘린더(.ics)로 알람을 받습니다.
- **비전 OCR & 환각 방어 챗봇:** 서류 3장을 찍으면 일정과 복약 주의사항을 추출하고, 보관된 텍스트 원문 안에서만 사실을 인용해 답변합니다.

## 2. 핵심 기능 명세

### 2.1. 5문항 온보딩 & 세션 자동 복원 (F-01)
- **질문 구성:**
  1. 입원 사유 (정형외과 / 암 / 뇌혈관 / 심장 / 외과 수술 / 일반 내과 질환)
  2. 퇴원일 (미정 가능, 과거 퇴원일 D+n 사후 가입 허용)
  3. 환자 출생연도 (만 나이 자동 환산) 및 퇴원 후 지낼 지역 (시·도, 서울은 자치구)
  4. 낮 시간 돌봄 공백 (혼자 계심 / 가족이 함께 있음 / 직장으로 낮에 비움)
  5. 가구 소득 구간 (수급·차상위 / 중위 100% 이하 / 중위 100~200% / 일반 / 잘 모르겠음)
- **세션 자동 복구 (UX 디테일):** 입력 중 전화가 오거나 창을 닫아도 `localStorage`에 자동 임시 저장되어 나중에 들어왔을 때 이전 작성 단계로 즉시 복구됩니다.
- **키패드 최적화:** 출생연도 등 숫자 입력 필드는 모바일에서 숫자 키패드가 바로 호출되도록 `inputMode="numeric"`, `maxLength={4}`를 적용합니다.

### 2.2. 2026 공공 복지 룰 엔진 (F-02)
- **26종 공공 복지 매칭:** 긴급복지 의료지원, 재난적의료비, 산정특례, 본인부담상한제, 장기요양등급, 서울 돌봄SOS, 가사간병 방문지원, 상병수당 등 26종 혜택을 결정론적 규칙으로 판정합니다.
- **판정 등급:** `[가능성 높음]` / `[확인 필요]` / `[해당 없음]`
- **만 65세 경계값 안전 분류:** 생일이 지나지 않은 경우와 지난 경우를 분기 계산하여 경계(만 64~65세)에 있는 환자는 "만 65세 경계에 있어 정확한 생일 기준 확인이 필요해요" 사유와 함께 안전하게 [확인 필요]로 분류합니다.
- **소득 미인지 안전망:** 온보딩에서 소득을 '잘 모르겠음'으로 선택해도 소득 조건 제도를 무조건 탈락시키지 않고 [소득 확인 필요]로 안내합니다.
- **원무과 서류 4종 교차 매칭:** 각 복지 제도에서 제출해야 하는 서류(진료비 영수증, 세부내역서, 입퇴원확인서, 장애인증명서)를 식별하여 화면에 연동 뱃지를 표시합니다.

### 2.3. 보험개발원 실손24 공공데이터 API 연동 (F-03)
- **Open API 연동:** 보험개발원 실손24 참여 요양기관 안내 서비스 API(`B552772/silson24/recuperation-institutions`) 연동.
- **고속 캐싱 및 상급종합병원 프리셋:** 56,706개 기관 데이터를 서버 메모리에 1시간 TTL로 캐싱하고, 공공 API 장애 시에도 주요 상급종합병원(서울대, 아산, 삼성, 세브란스, 성모 등) 프리셋을 통해 무중단 검색을 보장합니다.
- **자동 판별 및 서류 패키지 유도:** 병원명 검색 시 1초 만에 참여 여부(`yes`/`no`)를 판별하며, 미지원 병원은 퇴원 당일 반드시 발급받아야 하는 원무과 4종 서류를 필수 챙김으로 강조합니다.
- **스캔 서류 ↔ 4종 패키지 자동 연동:** 보관함에 영수증이나 확인서가 이미 스캔되어 있으면 `[보관함에 있음]` 뱃지와 함께 "보관함에 이미 스캔해 둔 서류가 있어요. 남은 서류만 챙기시면 돼요" 안내를 제공합니다.

### 2.4. 퇴원 타임라인 & 스마트 캘린더 연동 (F-04)
- **4단계 회복 사이클:**
  - 1단계: 퇴원 전 준비 (D-3 ~ D-1)
  - 2단계: 퇴원 당일 (D-Day)
  - 3단계: 집에서 회복 및 첫 외래 (D+1 ~ D+14)
  - 4단계: 정기 외래 및 마무리 (D+15 ~ D+180)
- **퇴원일 미정/변경 복원력:** 미정 상태에서는 상대 일정(D-3, D+7)으로 안내하며, 퇴원일이 변경되면 상대 일정만 자동 재계산하고 사용자가 직접 지정한 외래 진료일은 그대로 유지합니다.
- **개인 스마트폰 캘린더 (.ics):**
  - 개별 할 일 캘린더 등록 및 전체 일정 iCalendar 피드(`feedIcs`) 제공.
  - 전날 저녁 20:00, 당일 아침 08:30 이중 알람(VALARM) 자동 탑재.
  - 고정 UID 부여로 일정 수정 시 캘린더 앱 내 덮어쓰기 보장.
- **카카오톡 인앱 브라우저 1초 안내:** 카카오톡 웹뷰에서 다운로드 시 차단되는 문제를 방지하기 위해 User-Agent 감지 시 "오른쪽 아래 [···] → [다른 브라우저로 열기]" 안내 가이드를 노출합니다.

### 2.5. 가족 무가입 역할 분담 (F-05)
- **Capability URL:** 7일 유효 초대 링크(`/j/<토큰>`)로 가족이 이름만 입력하고 즉시 참여합니다.
- **동시 배정 충돌 방어 (Race Condition):** 동일한 할 일의 [내가 할게]를 0.1초 차이로 동시 클릭 시, DB 원자적 락을 통해 선점자에게 배정하고 후발 주자에게는 `"방금 {가족이름}님이 먼저 맡았어요"` 안내를 제공합니다.
- **동명이인 자동 번호 식별:** 같은 이름(예: 지은)으로 참여 시 자동으로 `지은 2`로 구분하여 활동 피드와 담당자 선택에서 혼선을 방지합니다.
- **담당자 없는 일정 '도움 요청 공유':** 아직 담당자가 없는 병원 일정의 [도움 요청 공유]를 누르면 카카오톡/문자에 바로 붙여넣을 수 있는 정중한 시스템 문구가 원클릭 복사됩니다.
  > `[첫 외래 진료 동행] (내일 (11/17)) 아직 담당 가족이 없어요. 시간 되시는 분이 맡아주세요.`

### 2.6. 비전 AI 서류 스캔 & 환각 차단 챗봇 (F-06)
- **서류 스캔 및 모션 UX:** 안내문, 약봉투, 영수증 촬영 시 화면 멈춤 불안감을 해소하기 위해 3단계 레이저 스캐닝 카드 애니메이션을 제공합니다.
- **핵심 주의사항 자동 뱃지 추출:** 스캔된 텍스트에서 보관 방법(냉장/차광/실온), 복약 시점(식후/공복), 주의사항(졸음운전 주의, 항생제 끝까지 복용)을 감지하여 노란색 뱃지로 자동 요약합니다.
- **날짜 없는 일정 방어:** 날짜가 불분명한 문장은 사용자가 직접 날짜를 지정하기 전까지 타임라인 등록 체크를 원천 차단합니다.
- **외래 예약증 중복 스캔 방어:** 같은 예약증을 중복 촬영해도 동일한 제목/날짜를 가진 일정은 중복 등록을 차단하고 `cycle_renewed` 이벤트의 중복 발화를 방지합니다.
- **챗봇 대기 UX:** 카카오톡형 타이핑 점(`···`) 모션을 노출하고, 2.5초 이상 지연 시에만 "답변을 준비하고 있어요" 문구를 띄워 시각적 피로도를 낮춥니다.
- **Pre-LLM 119 긴급 안내:** 흉통, 호흡곤란, 38.5도 이상 고열, 마비 등 응급 키워드가 감지되면 AI 답변 대기 없이 클라이언트에서 즉시 119 응급 안내 카드를 최우선으로 팝업합니다.

### 2.7. 일일 안부 체크 & 진료실 외래 리포트 (F-07)
- **저녁 안부 10초 체크:** 복약 여부(아침/점심/저녁), 체온, 통증 점수(0~10), 배변 상태를 하루 1회 기록합니다.
- **어제 기록 불러오기:** 어제 기록이 있는 경우 "어제 기록 불러오기 (통증 N점 · 정상 체온)" 원탭 버튼을 제공해 매일 슬라이더를 일일이 조작할 필요 없이 1초 만에 기록을 완료할 수 있습니다.
- **진료실 외래 리포트:** 14일간의 복약률, 평균 통증, 체온 변화, 메모를 한눈에 볼 수 있도록 의료진 제출용 가로보기 뷰를 지원합니다.

### 2.8. 맥락 UX 라이팅 & 아름다운 케어 졸업 (F-08)
- **시간대별 맥락 멘트:** 새벽 00~06시(응급 119 안내), 아침 06~12시(외래 신분증 챙기기), 저녁 18시 이후(10초 저녁 안부 체크) 시점별 맞춤 멘트를 제공합니다.
- **사후 가입자(D+n) 맞춤 첫인상:** 퇴원 후 7일 이내 유입된 보호자에게는 "퇴원하신 지 N일째네요. 놓친 서류와 미신청 지원금부터 먼저 점검해 드릴게요"로 상황을 인지한 맞춤 톤을 적용합니다.
- **주말 퇴원 원무과 휴무 사전 경고:** 월요일 퇴원 시 D-1(일요일)에 원무과와 주민센터가 쉬는 현실을 반영하여 토요일부터 사전 안내 배너를 띄웁니다.
- **쉬운 용어 사전 공백 무시 관용 검색:** "실손 24" vs "실손24", "산정 특례" vs "산정특례" 등 공백 차이에 구애받지 않고 실시간으로 용어를 찾아주며, 없는 단어는 씩씩이 챗봇 질의로 연결합니다.
- **케어 졸업 카드 & 삭제 전 안전 점검:** 완치 후 케이스 삭제 시 가족의 총 기여도(완료한 할 일 N개, 기록한 안부 M일) 요약 카드를 띄우고, "연말정산 장애인증명서와 실손 청구 서류를 모두 챙기셨나요?" 최종 안전장치를 확인합니다.

## 3. 디자인 시스템 및 UI 원칙

- **디자인 톤:** 단정하고 차분한 민트코어(Mint Core: `#0d6b56`, `#e8f5f0`, `#1a201c`).
- **엄격한 이모티콘 배제:** 서비스 신뢰도와 단정한 의료·돌봄 경험을 위해 화면, 버튼, 알림, 챗봇 어디에도 이모지(🎉, ⚠️, ❤️ 등)를 일절 사용하지 않으며, SVG 아이콘과 씩씩이 마스코트 컴포넌트(`components/Mascot.tsx`)만 사용합니다.
- **접근성(a11y):** 최소 44px 이상의 터치 타깃, WCAG AA 준수 고대비 색상, 1.5 이상의 행간을 유지합니다. 설정 화면에서 글자 크기(보통, 크게, 아주 크게)를 조절할 수 있습니다.

## 4. 데이터 보안 및 개인정보 원칙

1. **제로 리텐션(Zero-Retention) 원본 사진 미저장:** S-08 서류 촬영 사진은 서버 디스크나 스토리지에 저장하지 않으며 메모리 추출 즉시 파기합니다.
2. **주민등록번호 2중 마스킹:** AI 프롬프트뿐만 아니라 DB 저장 직전 정규식(`maskIds`)으로 생년월일 뒤 7자리를 `*******`로 강제 마스킹합니다.
3. **토큰 유출 방지 및 검색엔진 차단:** `next.config.ts`에 `Referrer-Policy: strict-origin-when-cross-origin`과 `/c/:path*`, `/j/:path*`에 `X-Robots-Tag: noindex, nofollow`를 기본 적용합니다.
4. **1년 미사용 데이터 자동 파기:** 마지막 이용일로부터 1년이 지난 케이스는 매일 자정 실행되는 자동 파기 크론(`/api/cron/purge`)을 통해 영구 삭제(Hard Delete)됩니다.
